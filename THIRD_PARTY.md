# Sources and dependencies

The OpenRaster document model, compositing formulas, editor bridge and CLI are implemented in MoonBit in this repository. The implementation follows the OpenRaster baseline specification and the SVG/W3C compositing definitions it references.

- OpenRaster baseline specification: https://www.openraster.org/baseline/baseline.html
- W3C Compositing and Blending: https://www.w3.org/TR/compositing-1/
- moonbitstack/moonzip 0.4.0 supplies ZIP archive handling.
- moonbitstack/moonxml 0.2.0 supplies XML parsing and serialization.
- moonbitstack/moonimage 0.2.0 supplies standalone image decoding (PNG, JPEG, WebP, GIF, BMP, TIFF and ICO) and PNG encoding.
- moonbitlang/x 0.5.7 supplies CLI filesystem access.
- [Milky2018/svg](https://github.com/Milky2018/svg) 0.6.1 is the source of the renderer in `internal/svg`. MoonOpenRaster updates the MoonBit derive syntax, Gaussian filtering and filter-primitive clipping. Milky2018/css and Milky2018/xml 0.6.1 remain registry dependencies. The Apache-2.0 licenses and distributed notices are included under LICENSES/.

Dependency source is installed through Mooncakes. Each dependency retains its own license. No dependency source is copied into this repository. The resolved runtime versions, full license copies and file-level asset scopes are recorded in LICENSES/manifest.json and LICENSES/README.md. The index identifies the materials and complete license copies required when redistributing them.

The small Light study regression fixture is generated by this project. Independent interoperability tests also construct ZIP/XML/PNG input with Python and Pillow. The browser bundles the source-layer artwork credited below.

Copies of the resolved dependencies' licenses and available NOTICE files are distributed under LICENSES/. The source package retains its MIT license; bundled dependency code retains the accompanying upstream licenses.

## Poster demonstration and web fonts

The workbench bundles a resized, format-converted version of David Revoy's **Poster for Capitole du libre 2023**, retaining the original seven painting layers and group. The source page states CC BY 4.0 and also carries an “AI derivation prohibited” statement, retained in LICENSES/capitole-artwork-NOTICE.txt. No generative image editing is involved. Layer names are translated; the image itself is only resized/normalized for the browser. The source archive is hash-pinned and conversion is reproducible with scripts/prepare_artwork.py. The artwork is not covered by this project's MIT license.

Inter (rsms/inter) and Instrument Serif (Google Fonts) are bundled locally for the interface and for SVG text using the generic sans-serif and serif families. The library includes exact Base64 copies of the same WOFF2 files. Their SIL Open Font License notices are included under LICENSES/font-*.txt. No remote font service is needed at runtime.


## Additional layered samples and practice variants

The sample collection also includes David Revoy's *In Bloom*, *Spooky Cute House* and *Rain City*, converted from the author's original layered KRA sources. Artwork remains under its own stated CC BY 4.0 terms and the author's additional notice. Source archive hashes, conversion details, rasterized adjustment effects and deliberately modified practice variants are documented in LICENSES/sample-artworks-NOTICE.txt and fixtures/sample-validation.json. The practice background replacement is extracted from the original Capitole background layer. No image-generation model is used to create or separate artwork layers.


The three format exercises in `web/assets/import-samples/` use project-original procedural artwork generated with Pillow and the MoonBit editor. They are covered by the project MIT license. The four David Revoy works retain the separate terms above.

## Full license copies and redistribution checks

`LICENSES/CC-BY-4.0.txt` contains the complete Creative Commons license for the distributed artwork; the artwork notices identify each work, author, source archive, source hash and modifications. The source terms and author's additional statement remain applicable. Dependency Apache-2.0 texts, the complete upstream MoonBit core NOTICE (including its third-party declarations), available module notices and both fonts' complete OFL texts are included separately. See [the distribution license index](LICENSES/README.md) for the exact scope; the project's MIT license applies to project code.

`python scripts/check_licenses.py` checks all bundled ORA, PNG and font files against the license map. The core source-file check verifies that the required license and notice files are included in its file list. The optional offline-web packager checks the license/notice bytes in its archive against the repository. License checks reject missing, truncated, stale or unmapped material. Contributor commands are described in [CONTRIBUTING.md](CONTRIBUTING.md).

SVG text with an explicit OpenType font uses mizchi/font 0.8.0 and its MoonBit shaping dependencies. Their sources and license copies are listed in [LICENSES](LICENSES/README.md). The project-generated test font is MIT-licensed.
