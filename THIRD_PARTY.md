# Sources and dependencies

The OpenRaster document model, compositing formulas, editor bridge and CLI are implemented in MoonBit in this repository. The implementation follows the OpenRaster baseline specification and the SVG/W3C compositing definitions it references.

- OpenRaster baseline specification: https://www.openraster.org/baseline/baseline.html
- W3C Compositing and Blending: https://www.w3.org/TR/compositing-1/
- moonbitstack/moonzip 0.4.0 supplies ZIP archive handling.
- moonbitstack/moonxml 0.2.0 supplies XML parsing and serialization.
- moonbitstack/moonimage 0.2.0 supplies PNG decoding and encoding.
- moonbitlang/x 0.5.7 supplies CLI filesystem access.

Dependency source is installed through Mooncakes. Each dependency retains its own license. No dependency source is copied into this repository. Review the resolved transitive licenses before publishing a bundled distribution.

The browser's Light study sample is generated by this project. The independent interoperability test generates its own ZIP/XML/PNG data using Python standard libraries and Pillow. No third-party artwork is included.

Copies of the resolved dependencies' licenses and available NOTICE files are distributed under LICENSES/. The source package retains its MIT license; bundled dependency code retains the accompanying upstream licenses.

## Poster demonstration and web fonts

The new workbench sample uses NASA/JPL's published The Grand Tour poster unchanged as a single image layer. Chinese title, subtitle, rule and source credit are newly drawn independent layers. See LICENSES/NASA-JPL-image-NOTICE.txt for the original page and image-use policy. The NASA/JPL image retains its source terms.

Inter (rsms/inter), Instrument Serif and Work Sans (Google Fonts) are bundled locally. Their SIL Open Font License notices are included under LICENSES/font-*.txt. No remote font service is needed at runtime.
