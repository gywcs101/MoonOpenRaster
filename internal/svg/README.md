# SVG renderer provenance

This package is adapted from the runtime source files of [Milky2018/svg 0.6.1](https://mooncakes.io/docs/Milky2018/svg%400.6.1), Copyright 2026 Milky2018. See the complete [Apache-2.0 license](../../LICENSES/Milky2018-svg-LICENSE) and [upstream NOTICE](../../LICENSES/Milky2018-svg-NOTICE).

MoonOpenRaster formats the sources with the current MoonBit toolchain, updates derive declarations, and implements filter subregions, separable premultiplied Gaussian filtering, color matrix modes, selected linear-RGB operations, and seeded fractal noise. The package remains in MoonBit and shares the same renderer across native, JS, wasm, and wasm-gc.
