## Verification and distribution

Run `python scripts/check_licenses.py` to check complete texts, source/license coverage of every bundled binary asset, resolved upstream licenses and notices. The core source-file check requires the license/notice files in its planned file list. The optional offline-web packager also verifies their bytes in its output archive. These checks cover their stated source-tree or archive scope; a source-file check alone does not verify a published registry package. Missing or stale notices fail the corresponding check.

Playwright and Pillow are development tools installed separately. Their implementation code is not included in the source or offline-web archives; `node_modules/` and `.mooncakes/` are excluded.
