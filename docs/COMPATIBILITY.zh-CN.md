# OpenRaster 0.0.6 图层兼容矩阵

目标是 [OpenRaster 0.0.6](https://www.openraster.org/baseline/baseline.html) Full baseline。下表记录当前实现范围。表格中的“原样保存”指复制输入归档。“写回”指从当前文档生成新归档和新预览。网页只读模式要求文件结构可检查、引用资源存在且原始 PNG 预览可以解码。

| --- | --- | --- | --- | --- |

像素位深以每通道计。工作台显示和拖动预览可能按 8 位显示，独立导出从原精度栅格重新计算。支持的 SVG 可编辑位置和图层属性。SVG 内部对象和文本内容请在矢量编辑器中修改。参见 [文件布局](https://www.openraster.org/baseline/file-layout-spec.html) 与 [图层栈规范](https://www.openraster.org/baseline/layer-stack-spec.html)。


## 独立图片导入

导入格式适用于新增和替换图层。新 ORA 保留 SVG 源文件，栅格素材使用 PNG 保存；导入能力和 ORA 原有图层类型的兼容范围分别见下表与上表。

| 输入格式 | 导入行为 |
| --- | --- |
| PNG | 静态 8/16 位及常见灰度和索引 PNG；保留透明度。 |
| JPEG（JPG） | 常规 JPEG 和受支持的渐进式 JPEG；应用 EXIF 方向。现有解码器无法正确处理部分渐进式文件的边缘采样，导入时会明确拒绝。 |
| WebP | 静态有损和无损 WebP；支持解码器可读的透明度。动画 WebP 给出错误。 |
| GIF | 读取逻辑画布上的第一帧，保留透明像素。 |
| BMP | 支持解码器可读的常规 BMP。 |
| TIFF（TIF） | 读取第一页、应用方向标记，保留支持的 16 位样本。分块 TIFF 等未支持的变体报错。 |
| ICO | 读取最大的图标图像。 |
| SVG | 读取自包含静态子集，保留 SVG 源，以像素参与当前文档的合成。 |

带未支持色彩标记的图片会报错。JPEG、WebP 和 GIF 的嵌入 ICC 不做转换。HEIC 和 AVIF 当前不能从这个入口导入。

## SVG 图层

支持 UTF-8 和带字节顺序标记的 UTF-16 SVG。已验证的静态内容包括几何形状、路径、变换、渐变、剪裁、内部 CSS、归档内 CSS 样式表声明和同文件图形复用。ORA 中的 SVG 可引用归档内相对路径的 CSS、PNG、常规 JPEG、SVG 图像和片段（含嵌套命名视图与带变换的视图），也可使用内嵌 PNG、常规 JPEG 或 SVG。编辑图层位置、透明度或顺序后，保存会保留 SVG 源和对应资源。独立导入 SVG 时，请使用自包含文件。

SVG 可使用归档内的 OpenType、WOFF 或 SVG 路径字形，也可把字体内嵌在 SVG 中。省略字体时用 Inter，声明通用 `sans-serif` 或 `serif` 时分别用 Inter 或 Instrument Serif。横排文字在主字体缺少字形时，可按字体列表使用随稿的备用 OpenType 字体。没有可用字形时会给出诊断。需保留原稿字形或展示中文时，请让文件附带所用的字体。已验证字体粗细与斜体选择、嵌套居中、字距、单行 `textLength`、文字引用、沿路径排字、单行右向左排列、带方向嵌入或显式覆盖的双向文字片段，从左到右文字及其嵌套片段的逐字定位和旋转，以及单个右向左文字节点的绝对定位和相对位移，以及各自指定横纵坐标的样式片段。随稿 OpenType 支持常用汉字与拉丁字母的竖排和普通竖排片段。复杂脚本中需连写的跨字体字形、嵌套样式下的双向文字逐字定位、竖排片段的绝对定位及路径上的自动字距仍待验收。

SVG 尺寸可用像素宽高或 `viewBox` 指定，当前上限为单边 2048 像素和源文件 256 KiB。已验证的效果包括亮度蒙版、偏移、高斯模糊、颜色矩阵和分形噪声。遇到不支持的内容时，工作台会提示限制，可用原始预览进行结构检查和原样保存。完整基线的条款与验证进度见 [基线核对记录](BASELINE.zh-CN.md)。
