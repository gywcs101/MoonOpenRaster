# 分层图像工作台使用说明

在完整 GitHub 仓库的根目录运行 `python scripts/serve_web.py`，然后访问
http://127.0.0.1:8765/ 。首次安装步骤见 [README](../README.md)。如果服务已经运行，可以直接打开该地址；修改代码后需要重新编译时，再停止旧服务并启动。
所有脚本、字体和示例都在本机，文件不会上传。

## 先体验真实原稿

默认载入 David Revoy 为 Capitole du libre 2023 创作的海报插画。
它包含作者原来的 7 个绘画图层和 1 个图层组，保留线稿、底色、修饰、
阴影、隐藏的草稿及粗线稿备选。我们仅转换格式、缩小尺寸、翻译图层名称，
没有从成品图片猜测图层，也没有另加图画内容。来源和授权见左下角及
`LICENSES/capitole-artwork-NOTICE.txt`。

1. 点击“阴影”旁的眼睛，再打开，观察颜色和明暗变化。
2. 隐藏“线稿”，看底色怎样独立存在；重新打开线稿。
3. 选择“线稿”，在蓝色框内拖动，线条会跟随移动，底色保持原位。
   这会让原稿的线条与颜色错位，恰好能看清两者是独立图层。
4. 点击“撤销”，一次撤回整个拖动。可显示草稿，但草稿会与完成稿叠加。

一个绘画层里可能有多个物体，移动时它们会一起移动。
例如这份原稿的线稿层包含多只企鹅，不能仅靠拖动单独移动其中一只。
本项目处理原稿已有的图层，不会自动识别或拆分层内物体。

## 常用操作

| 操作 | 方法 |
| --- | --- |
| 移动整层 | 选择绘画层，拖动蓝色框；也可填写 X、Y 后应用 |
| 撤销 / 重做 | 顶栏按钮，或输入框外按 Ctrl+Z / Ctrl+Shift+Z（也支持 Ctrl+Y） |
| 放大 / 缩小 | 在画布上滚轮，或使用上方的 − / ＋ |
| 查看原始像素大小 | 点击 100% |
| 全图显示 | 点击“适应” |
| 平移画布 | 按住空格拖动、按鼠标中键拖动，或启用“手形”后拖动 |
| 对照导入时的画面 | 勾选“对照导入时画面”；此时不显示可拖动选框 |
| 导入图片为图层 | 左侧“导入图片”；选中组时放入该组，否则放在当前同级最上方 |
| 替换某层图片 | 选择绘画层后点击“替换图片”；保留名称、位置和混合属性 |
| 新建图层组 | 左侧“新建组”；再用右侧“移入图层组”整理现有层 |
| 复制 / 删除 / 排序 | 右侧图层管理和图层顺序按钮；复制支持整个嵌套组 |
| 锁定 | 右侧“锁定图层”；锁定组同时保护其子层 |
| 单层导出 | 右侧“导出此层 PNG” |
| 全部层导出 | 左侧“提取全部层”，下载 PNG 和 `layers.json` 的压缩包 |
| 整图导出 | 顶栏“导出 PNG” |
| 保留分层继续编辑 | 顶栏“保存 ORA”，可在 Krita 中重新打开 |

「导入图片」和「替换图片」都支持 PNG、JPEG、静态 WebP、GIF、BMP、TIFF、ICO 和受支持的静态 SVG。GIF 取第一帧，TIFF 取第一页，ICO 取最大图标；16 位 PNG 和受支持的 16 位 TIFF 保留通道精度。保存 ORA 后，栅格素材按独立 PNG 图层保存，SVG 保留原始矢量源文件。仓库版本打开含 SVG 的 ORA 时，可保留和使用 SVG 引用的归档内 CSS、PNG 和 SVG 片段，也可在合成时使用通过 `@font-face` 明确指定的随稿字体。若导入失败，原来的图层保持不变。遇到没有支持的色彩配置或编码变体时，工具会显示错误；处理边界见 [兼容矩阵](COMPATIBILITY.zh-CN.md)。

## 几个容易误会的地方

- “图层名称”只改变列表中的名字，不会更改已经画成像素的文字。
- 拖动时会先显示较低分辨率的预览，松手后恢复清晰画面；导出始终使用完整分辨率。
- 一次拖动只占一个撤销步骤。按 Esc、取消触摸或窗口失去焦点时放弃这次拖动。
- 撤销最多 20 步，并按图层像素内存自动缩短，超过范围的旧步骤会释放。
  重新导入文档或重载示例后历史清空；撤销后做新编辑会清空重做分支。
- 锁定只影响这次网页编辑，不写入 ORA；结构操作、撤销和重做后会清除锁定。
- 单层导出提取的是图层本身，保留该层尺寸和原始像素，不把整层透明度、
  位置、混合方式烘焙进去。压缩包清单记录这些属性和原始图层路径。
- 浏览器最多导入 32 MiB 文件。支持 8 位与 16 位 sRGB 栅格 ORA，画布底部显示合成位深，当前栅格层的属性区标出 16 位图层。16 位文档保存 ORA 或导出整张 PNG 时保留合成精度。
- 遇到无法处理的色彩配置或渲染功能，仅在原始预览有效时提供只读查看和原样保存。可按 [兼容矩阵](COMPATIBILITY.zh-CN.md) 查阅具体边界。

## 如何检查修改成功

先移动线稿，保存 ORA，再用“打开 ORA”载入刚保存的文件，检查位置、图层和
画面。再用 Krita 打开该文件，确认依然是独立图层。

## 样例库与四步练习

点击顶栏“样例与练习”。每份作品都有“查看原稿”和“开始练习”两个入口。
原稿保持导出后的原始状态；练习有意调整了部分图层，供你修改，不能把练习起点当作作者的原稿。

| 样例 | 练习目标 |
| --- | --- |
| 自由之都 | 对齐线稿、隐藏草稿、用提供的原稿白底 PNG 替换浅绿背景，再导出 |
| 花间少女 | 隐藏完成稿补绘与预设色彩，保留明暗底稿，调整铅笔线条，制作素描变体 |
| 林间小屋 | 关闭透视辅助组、修复前景错位、恢复后期气氛，再导出 |
| 雨城 | 关闭黑白构图检查与透视线，把雨幕不透明度调到 20%–35%，制作小雨版本 |

练习区会自动检查当前图层状态。“定位图层”帮你选中要操作的层；你可以用
右侧属性、眼睛按钮或拖动完成，也可以使用指引提供的参考值按钮。
“参考成图”可对照练习前后的效果。“更换背景”步骤还提供可下载的原稿 PNG，
无需另找图片。需要替换的是整层图片，而不是画面里的某一个物体。

一次练习有三个改图步骤和一个导出步骤。前三步完成后，点击“导出 PNG”，
也可以用顶栏保存 ORA，保留图层结构。任务按参考条件检查，不妨碍你随时自由导出。

完成状态会随文档变化：撤销可能使任务重新变成待完成；更改已经导出的图像后，
需要再次导出。重新练习会清空这次进度。切换样例、重置或打开其他文件前，
若改动尚未保存为 ORA，页面会让你选择保留当前编辑或放弃后切换。
重开导出的 ORA 会按普通本地文件处理，不会自动恢复练习身份。

新增样例保留原始图层与转换说明。雨城原 KRA 的两项调整效果由 Krita 烘焙为
可交换的栅格结果，网页不承诺重新编辑这些 KRA 调整器。来源见每份作品左下角。

素材来源、格式转换和授权见 [第三方说明](../THIRD_PARTY.md) 与 [许可索引](../LICENSES/README.md)。需要修改网页或补充测试时，参阅 [开发与贡献](../CONTRIBUTING.md)。

## 图片格式练习

「样例与练习」上方有三套原创练习。每套都提供编辑起点、参考成图和原格式素材。可以用引导按钮完成一步，也可以下载素材后用左侧「导入图片」或右侧「替换图片」执行同样的操作。

| 练习 | 素材 | 操作 |
| --- | --- | --- |
| 海岸明信片 | JPEG 海岸图、透明 WebP 邮戳、透明 PNG 波形 | 替换照片，添加并移动两个图层，调低邮戳不透明度。 |
| 地形测绘图 | 16 位灰度 TIFF、BMP 图例、SVG 等高线 | 替换地形图、导入图例，移动等高线，检查 16 位 PNG 和 ORA 重开后的 SVG 图层。 |
| 夜间车站 | 动画 GIF、多尺寸 ICO | 用 GIF 第一帧替换灯牌，导入最大图标，移动站标并隐藏灯牌。 |

SVG 图层的属性区会标出「SVG 矢量」。可以拖动、复制、调透明度或更换整个 SVG 文件。修改 SVG 内的路径请使用矢量绘图工具。

练习完成后可导出 PNG，或保存 ORA 再重新打开。保存的 ORA 保留独立图层。练习素材为项目原创，按 MIT 分发。
